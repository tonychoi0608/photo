# 📸 여친 인생샷 카메라

사진 초보도 포토그래퍼처럼 찍게 도와주는 **웹 카메라 앱** (설치 없이 브라우저에서 바로 실행, 홈 화면에 추가 가능).

## 주요 기능
| 기능 | 설명 |
|---|---|
| 👻 실루엣 가이드 | 추천 포즈를 화면에 반투명 그림자로 띄움. 인물을 그 안에 맞추면 끝 |
| 🧭 실시간 코칭 | 머리 잘림 / 무릎·발목(관절) 잘림 / 한 걸음 앞·뒤 / 좌우 이동 / 수평 / 내려찍기 경고 / 역광·어두움 |
| 🎯 일치도 점수 | 셔터 링에 0~100점. 실루엣과 맞으면 초록색 |
| 🤖 AI 자동촬영 | 점수가 기준 이상으로 0.6초 유지되면 자동 촬영 |
| 🏖️ 상황 인식 | 온디바이스 AI가 바다·산·꽃·카페·거리·명소·실내·노을·야경 판단 → 포즈·색감·팁 자동 추천 |
| 👥 사람 추가 | 두 명 감지 시 커플 포즈 제안, 둘이 모드에선 타이머 10초 안내 |
| 🤳 셀카 모드 | 전면 카메라 자동 전환, 얼굴 실루엣 + 눈 높이선, 너무 가까움(왜곡)·올려찍기(이중턱)·얼굴 위치 코칭, 🖐 손 들면 3초 뒤 촬영, 💡 링라이트 + 화면 플래시, 셀카 포즈 7종 |
| 🎨 자동 색보정 | 화이트밸런스, 자동 레벨, 노출(어두운 사진만 밝게), 역광 그림자 복원, 피부 보호 바이브런스, 글로우, 비네팅 + 프리셋 7종 |
| 🎞️ 연사 | 셔터 길게 누르면 5장 연사 (걷기·머리 넘기기·점프용) |
| 💾 사진첩 저장 | 아이폰: 공유 시트 → "이미지 저장" / 안드로이드·PC: 바로 저장(갤러리 표시) |
| 🤖 GPT-5.4 분석 (선택) | 설정에 OpenAI 키 입력 시 가이드에서 현재 화면을 전문가처럼 분석 |

## 폰에서 쓰려면 (HTTPS 필수)
카메라는 보안상 **https 주소**에서만 켜집니다. 가장 쉬운 방법:

1. https://app.netlify.com/drop 접속 → 이 `photo` 폴더를 통째로 끌어다 놓기
2. 나온 `https://xxxx.netlify.app` 주소를 폰에서 열기
3. 사파리/크롬 메뉴 → **홈 화면에 추가** 하면 앱처럼 전체화면으로 실행

(GitHub Pages, Vercel, Cloudflare Pages 등 정적 호스팅 어디든 가능. 빌드 과정 없음)

## PC에서 테스트
```bash
python -m http.server 5173
```
→ http://localhost:5173 (웹캠 사용)

## 구조
```
index.html            화면 구성
css/style.css         스타일
js/app.js             카메라·UI·촬영·저장 메인 로직
js/vision.js          MediaPipe 포즈 인식 + 장면 분류 (브라우저 내 실행)
js/coach.js           실루엣 배치, 일치도 점수, 코칭 메시지
js/poses.js           포즈 라이브러리 (혼자 10종 + 둘이 5종 + 셀카 7종)
js/scenes.js          상황별 추천 포즈·색감·팁
js/color.js           자동 색보정 엔진 + 프리셋
js/ai.js              (선택) GPT-5.4 Responses API 분석
```

## 참고
- 사진/영상은 기기 밖으로 나가지 않음 (GPT 분석 버튼을 누른 경우만 해당 프레임 1장이 OpenAI로 전송)
- 첫 실행 시 AI 모델(약 10MB)을 내려받느라 몇 초 걸림
- 브라우저 API 한계로 촬영 해상도는 카메라 영상 스트림 해상도(보통 1080p~1440p)
- 포즈 추가: `js/poses.js`의 `POSES` 배열에 키포인트 좌표로 추가하면 썸네일·실루엣·점수 모두 자동 적용
